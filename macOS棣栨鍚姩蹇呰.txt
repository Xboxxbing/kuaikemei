【你现在的情况：文件放在桌面，终端一直不成功】

原因找到了：之前教程里的命令写的是
    cd ~/Downloads/quickmix-site && node server/app.js
那是「下载」文件夹的路径。你的文件在【桌面】，cd 第一步就
失败，&& 后面的启动命令根本没执行。不是你操作错，是路径给错了。

好消息：这个服务按自己所在的位置找文件，根本不需要 cd，
也不需要 &&。下面「方式 0」最稳，连文件夹叫什么、放哪儿
都不用管。


================================================================
  方式 0（最推荐，100% 成功：把文件拖进终端）
================================================================
1. 按 Command + 空格，输入「终端」，回车，打开终端窗口。

2. 在终端里敲：   node
   注意：node 后面要有一个【空格】，千万别漏。
   敲完先别回车。

3. 在 Finder 里打开：
       桌面 → quickmix-site → server
   把里面的 app.js 文件【直接拖进终端窗口】。
   终端会自动填出完整路径，看起来像：
       node /Users/你的用户名/Desktop/quickmix-site/server/app.js

4. 按【回车】。看到「前台首页：http://localhost:3000/」就成了。
   浏览器打开 http://localhost:3000/
   后台是 http://localhost:3000/admin  （admin / admin）

   ★ 整个过程不用 cd、不用记路径、不用执行任何脚本文件，
     所以 macOS 那个「Apple 无法验证」警告也不会出现。
   ★ 终端窗口不能关，关了网站就停；停止按 Ctrl + C。
   ★ 端口 3000 被占用会自动顺延，以终端实际输出的地址为准。


================================================================
  方式 A（不想拖？复制这一行，桌面专用）
================================================================
    node ~/Desktop/quickmix-site/server/app.js

文件夹名不确定（带 (1)、带空格、或里面还套了一层）？用这条自动找：

    node "$(find ~/Desktop -path '*/server/app.js' | head -1)"

文件在「下载」而不是桌面？把上面的 ~/Desktop 换成 ~/Downloads。


================================================================
  终端报错对照表
================================================================
cd: no such file or directory / No such file or directory
    → 路径不对。别再用带 cd ~/Downloads 的老命令，用方式 0 或方式 A。

node: command not found / zsh: command not found: node
    → 没装 Node.js。去 https://nodejs.org 下载左边 LTS 版双击安装，
      装完把终端【关掉重开】再执行。先敲 node -v 验证，
      出现 v20.x 之类就装好了。

Error: Cannot find module
    → 拖错文件了。要拖 server 文件夹里那个 app.js。

syntax error / 一堆乱码 / command not found: cd~
    → 复制时带了中文引号、全角 ＆ 或漏空格。手动敲一遍。

Port 3000 is already in use 或地址变成 3001
    → 正常，会自动换端口，以终端打印的地址为准。

终端一片空白、没有任何输出
    → 可能拖进去的是文件夹而不是文件，或忘了按回车。重做方式 0 的第 2～4 步。

还不行？把终端里的【报错原文】复制发给我，我按报错给你一条能直接用的命令。


================================================================
  另：双击 start-mac.command 弹「Apple 无法验证」
================================================================
这是 macOS 对【网上下载的未签名脚本】的例行检查，不是文件坏了。
脚本内容只有「检查 Node → 换端口 → 启动本地服务 → 打开浏览器」，
没有联网下载、没有 sudo、不改系统文件。

为什么上个版本没事、这个版本又弹？
  macOS 的放行只认「具体那一个文件」。每次重新下载 / 重新解压，
  start-mac.command 都是新文件、被重新打上隔离标记，所以要再放行
  一次。旧文件当时已放行过，新文件没有。

方式 B（永久解决，100% 有效：清掉整包隔离标记，之后随便双击）
    cd ~/Desktop/quickmix-site && xattr -dr com.apple.quarantine . && chmod +x start-mac.command

还没解压？也可以先对 zip 清除再解压，解压出来的文件就都是干净的：
    xattr -d com.apple.quarantine ~/Desktop/quickmix-site.zip

方式 C（不想开终端：试着让系统放行一次）
  右键 start-mac.command → 「打开」→ 弹窗里点「打开」；
  或 系统设置 → 隐私与安全性 → 「仍要打开」。
  ⚠ 较新的 macOS 对未签名脚本可能只给「完成 / 移到废纸篓」
    两个按钮、没有「打开」。如果是这种弹窗，别较劲，
    直接用方式 0 或方式 A，这两个 100% 有效。

已点了「移到废纸篓」？没关系，重新解压 zip 即可，文件本身没问题。

若提示「权限不够」而不是安全警告：
    cd ~/Desktop/quickmix-site && chmod +x start-mac.command
