快可美 quick-mix 官网 · 部署与运行指南

适用：macOS（你现在的电脑）· Windows · Linux 服务器。整站零依赖，不需要 npm install，装好 Node.js 就能跑。

✅ 文件放在桌面 / 终端一直不成功？照这 4 步做

先说原因：早期版本教程里的命令写的是 ~/Downloads/quickmix-site（下载文件夹），你的文件在桌面，所以 cd 第一步就失败了，后面的 && node ... 根本没执行。不是你操作错，是路径不对。

还有个好消息：这个服务是按自己所在的位置找文件的，根本不需要 cd，也不需要 &&。所以最稳的办法是——把文件拖进终端，连文件夹叫什么、放哪儿都不用管。

🌟 万能拖拽法（不管文件夹叫 quickmix-site、quickmix-site 2 还是别的名字，都能用）

1
按 Command + 空格，输入「终端」，回车打开终端。
2
在终端里输入 node —— node 后面要有一个空格，千万别漏。
3
在 Finder 里打开 桌面 → quickmix-site → server 文件夹，把里面的 app.js 文件直接拖进终端窗口。终端会自动填出完整路径，看起来像：
node /Users/你的用户名/Desktop/quickmix-site/server/app.js
4
按 回车。看到「前台首页：http://localhost:3000/」就成功了，浏览器打开这个地址；后台是 /admin。
整个过程不用 cd、不用记路径、不用执行任何脚本文件，所以 macOS 的「无法验证」警告也不会出现。
终端窗口不能关（关了网站就停）；停止服务按 Ctrl+C。端口 3000 被占用会自动顺延，以终端实际输出的地址为准。

不想拖？直接复制这两条也行（桌面专用）

node ~/Desktop/quickmix-site/server/app.js

文件夹名不确定（带 (1)、带空格、或者套了一层）？用这条自动找，粘进终端回车即可：

node "$(find ~/Desktop -path '*/server/app.js' | head -1)"

文件不在桌面而在「下载」？把上面命令里的 ~/Desktop 换成 ~/Downloads。

⚠ macOS 弹「Apple 无法验证 start-mac.command」？先看这里

这是 macOS 对网上下载的未签名脚本的例行检查，不是文件坏了。脚本内容只有「检查 Node → 换端口 → 启动本地服务 → 打开浏览器」，没有联网下载、没有 sudo、不改系统文件。

为什么上个版本没事、这个版本又弹：macOS 的放行只认「具体那一个文件」。每次重新下载 / 重新解压，start-mac.command 都是新文件、被重新打上隔离标记，所以要再放行一次。旧文件当时已放行过，新文件没有。

最省事：完全不碰那个脚本，直接用终端启动（macOS 不会拦截）

node ~/Desktop/quickmix-site/server/app.js

（复制按钮若没反应，直接拖选上面那行文字按 Cmd+C 也行。）
看到「前台首页：http://localhost:3000/」即成功。终端窗口别关，关闭 = 网站停止；停止按 Ctrl+C。

  1. 一条命令永久清掉整包隔离标记（100% 有效，之后双击就能用）：
    cd ~/Desktop/quickmix-site && xattr -dr com.apple.quarantine . && chmod +x start-mac.command
    还没解压？也可以先对 zip 执行 xattr -d com.apple.quarantine ~/Desktop/quickmix-site.zip 再解压，解压出来的文件就都是干净的。
  2. 不想开终端：右键 start-mac.command → 「打开」→ 弹窗里点「打开」；或去 系统设置 → 隐私与安全性 → 仍要打开。注意：较新的 macOS 对未签名脚本可能只给「完成 / 移到废纸篓」两个按钮、没有「打开」，这种情况下直接用上面第 1 条或方式 A。
  3. 若提示「权限不够」而非安全警告：chmod +x start-mac.command。

同目录另有一份纯文本 macOS首次启动必读.txt，双击用文本编辑打开，不会触发任何警告。若你已经点了「移到废纸篓」，重新解压 zip 即可，文件本身没问题。

先搞清楚一件事：这个网站分两部分——前台（客户看的 14 个页面）和后台（你自己改内容的管理系统，地址后面加 /admin）。两者由同一个 Node 程序提供，所以只要服务在跑，前后台都能用。

一、先在本机跑起来（5 分钟）macOS + Windows

1安装 Node.js（只需做一次）

打开 https://nodejs.org ，下载页面上左边那个 LTS 版本（长期支持版，比如 20.x LTS），双击安装包一路「下一步」即可。

  • macOS 下载 node-v20.x.x.pkg，双击安装。
  • Windows 下载 node-v20.x.x-x64.msi，双击安装，勾选 "Add to PATH"（默认已勾）。

验证是否装好 —— 打开终端macOS：Command + 空格 搜「终端」Windows：Win + R 输入 cmd，执行：

node -v

显示 v20.x.x 之类就成功了。如果提示「不是内部或外部命令」，说明没装好或没加 PATH，重启电脑再试。

2解压并启动（推荐：终端一行命令）

把 quickmix-site.zip 解压，得到一个 quickmix-site 文件夹。

路径要求（Windows 用户特别注意）：文件夹请放在不含中文和空格的路径下，例如 D:\quickmix-site 或 C:\quickmix-site。不要放在「桌面\新建文件夹(2)\快可美 官网」这类路径里。
推荐用终端启动 —— 这一行只是让已装好的 Node 运行我们自己的程序，不执行任何脚本文件，所以 macOS 不会弹「无法验证」的警告，也不会触发 Windows SmartScreen。

macOS 打开「终端」（Command + 空格 搜「终端」），粘贴：

node ~/Desktop/quickmix-site/server/app.js

Windows 打开 cmd 或 PowerShell，粘贴：

cd /d D:\quickmix-site && node server/app.js
小技巧（macOS）：不用手敲路径。先输入 cd （cd 加一个空格），然后把 quickmix-site 文件夹直接拖进终端窗口，路径会自动填上，再敲 && node server/app.js 即可。
文件不在桌面？把 ~/Desktop 换成实际位置（如 ~/Downloads）；更省事的做法见顶部的「拖拽法」，完全不用记路径。

终端窗口会显示：

================================================
 quick-mix 快可美官网已启动
================================================
 前台首页： http://localhost:3000/
 管理后台： http://localhost:3000/admin
 后台账号： admin        密码： admin
 数据文件： .../server/data/db.json

 保持这个窗口开着 = 网站就在运行；关掉窗口 = 网站停止
================================================

浏览器打开 http://localhost:3000/；后台是 /admin。端口 3000 被占用时脚本会自动顺延，以终端实际输出的地址为准。

记住三件事：
① 那个终端窗口不能关，关了网站就停了；
② 改内容进 http://localhost:3000/admin，账号密码都是 admin；
③ 停止服务：在窗口里按 Ctrl + C。

3可选：双击脚本启动（首次需放行一次）

如果你更喜欢双击，文件夹里也提供了两个启动脚本：

  • macOS 双击 start-mac.command
    首次会弹「Apple 无法验证…」：右键该文件 → 「打开」→ 弹窗里点「打开」；或去 系统设置 → 隐私与安全性 → 仍要打开。也可一条命令永久解决：xattr -dr com.apple.quarantine .。详见顶部红框。
  • Windows 双击 start-windows.bat
    若弹「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」；防火墙询问选「允许访问」。

双击脚本会自动检测 Node、端口占用自动顺延、自动打开浏览器，效果和终端命令完全一样。被系统拦住时，改用上面的终端命令即可，不必反复和弹窗较劲。

二、让手机 / 同事电脑也能访问同一 WiFi 下

本机跑起来后，同一 WiFi 下的设备可以用你的局域网 IP 访问，适合给同事、客户现场演示。

macOS 查本机 IP：系统设置 → 网络 → Wi-Fi → 详细信息；或终端执行：

ipconfig getifaddr en0        # Wi-Fi
ipconfig getifaddr en1        # 有线（视机型而定）

Windows 终端执行 ipconfig，找「IPv4 地址」那一行，比如 192.168.1.23。

然后其它设备浏览器访问 http://192.168.1.23:3000/ 即可（把 IP 换成你自己的）。

如果访问不了，多半是防火墙拦了。macOS：系统设置 → 隐私与安全性 → 防火墙 → 关闭，或允许 Node 入站连接。Windows：防火墙弹窗时选「允许」，或在「允许应用通过防火墙」里勾上 Node.js。

三、正式上线：部署到云服务器从你的 Mac 操作

要让全国客户都能访问，需要一台有公网 IP 的云服务器。推荐腾讯云或阿里云的轻量应用服务器，2 核 2G 配置即可（几十到一百元/月，新用户常有优惠）。

1买服务器

选项建议
厂商腾讯云轻量应用服务器 / 阿里云轻量应用服务器（国内访问快，备案方便）
配置2 核 2G、40G SSD、3~5M 带宽（美缝站图片不多，完全够用）
系统镜像Ubuntu 22.04 LTS（本文命令以此为准，选它最省事）
地域选离你近的，比如「上海」「广州」

买完在控制台能看到：公网 IP、root 密码（需重置一次才能拿到）。

防火墙要放行端口：在云厂商控制台的「防火墙 / 安全组」里，放行 22（远程登录）、80（网站）、443（HTTPS）。不放行网站打不开。

2从 Mac 远程连上服务器

macOS 自带 ssh，不用装任何软件。打开「终端」：

ssh root@你的公网IP

首次连接问 Are you sure you want to continue connecting? 输入 yes 回车，再输入密码（输入时屏幕上不显示，正常，输完直接回车）。

Windows 用户可用自带 PowerShell（Win10+ 自带 ssh），或装 Xshell / FinalShell / MobaXterm（FinalShell 免费好用，还能直接拖文件上传）。

3在服务器上装 Node.js

# Ubuntu / Debian 用这条
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs

# CentOS / Rocky 用这条
curl -fsSL https://rpm.nodesource.com/setup_20.x | bash -
yum install -y nodejs

# 装完验证
node -v        # 显示 v20.x.x 即可

4把网站文件传到服务器

方式 A：在 Mac 终端用 scp（一条命令搞定）

# 注意：在「你自己的 Mac」上执行，不是在服务器上
cd ~/Downloads
scp quickmix-site.zip root@你的公网IP:/root/

方式 B：用 FileZilla（图形界面，不熟命令就用这个）
下载 FileZilla Client → 顶部填：主机 sftp://你的公网IP、用户名 root、密码、端口 22 → 快速连接 → 左边找到本地的 zip，拖到右边。

然后在服务器上解压：

ssh root@你的公网IP
apt install -y unzip        # 没有 unzip 就装一下
cd /root
unzip quickmix-site.zip
cd quickmix-site
ls

5用 pm2 让它 24 小时常驻

直接 node server/app.js 在你关掉终端后会停止，所以要 pm2（进程守护，还能自动重启）：

npm install -g pm2
cd /root/quickmix-site
pm2 start server/app.js --name quickmix
pm2 save
pm2 startup        # 开机自启：把这条命令输出的那一行再复制执行一次

常用命令：

pm2 status          # 看状态，running 就是正常
pm2 logs quickmix   # 看日志（报错看这里）
pm2 restart quickmix
pm2 stop quickmix

现在访问 http://你的公网IP:3000/ 应该能看到网站了。

6绑定域名（用 80 端口访问，去掉 :3000）

装 nginx 做反向代理，让用户访问 www.你的域名.com 即可：

apt install -y nginx

新建配置文件：

nano /etc/nginx/conf.d/quickmix.conf

粘贴以下内容（把 www.你的域名.com 换成真实域名）：

server {
    listen 80;
    server_name www.你的域名.com 你的域名.com;

    client_max_body_size 20m;   # 后台上传图片需要

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}

按 Ctrl+O 回车保存，Ctrl+X 退出。然后：

nginx -t                  # 检查配置，显示 successful 才行
systemctl reload nginx
systemctl enable nginx    # 开机自启

最后到域名注册商后台（万网/腾讯云等）做一条解析：类型 A，主机记录 www，记录值填服务器公网 IP。等几分钟生效。

备案：服务器在中国大陆，域名必须 ICP 备案后才能正常访问（不备案会被拦截）。在云厂商后台有现成的备案流程，按提示提交营业执照等材料，一般 10~20 个工作日。备案期间可以先用 IP 访问测试。

7加 HTTPS（小绿锁，可选但建议做）

apt install -y certbot python3-certbot-nginx
certbot --nginx -d www.你的域名.com -d 你的域名.com

按提示输入邮箱并同意条款，证书会自动配置，到期自动续期。之后访问 https://www.你的域名.com 就有小绿锁了。

四、不买服务器：临时公网演示内网穿透

只想先给客户看一眼效果、不想买服务器时，用内网穿透把本机 3000 端口暴露到公网。适合演示，不适合长期正式使用（免费版地址会变、速度慢）。

# 1. 本机先按第一章把网站跑起来（localhost:3000）

# 2. 装 cpolar（Mac 用 Homebrew）
brew install cpolar/tap/cpolar

# 3. 另开一个终端窗口执行
cpolar http 3000

它会给出一个 https://xxxxx.cpolar.cn 之类的公网地址，发给客户即可。Windows 用户去 cpolar 官网下载客户端，效果一样。同类工具还有 natapp、花生壳、frp。

问题说明 / 解决办法

五·补三、后台进不去 / 菜单点不动

现象原因与解决

六、日常运维

备份（重要）

所有内容都在一个文件里：quickmix-site/server/data/db.json。定期拷走它就行（外加 public/uploads/ 里你上传的图片）。

# 服务器上做一次备份
cp /root/quickmix-site/server/data/db.json /root/db-$(date +%F).json

# 从服务器下载备份到你的 Mac（在你 Mac 上执行）
scp root@你的公网IP:/root/quickmix-site/server/data/db.json ~/Desktop/db-backup.json

在服务器上改内容后，同步到"双击打开"模式

后台改完内容后，如果还想让 public/index.html 双击打开也显示新内容，执行一次：

node tools/gen-fallback.js

恢复出厂示例数据

停掉服务 → 删除 server/data/db.json → 重启，会自动从 seed.json 重新生成。

更新网站内容（推荐流程）

  1. 浏览器进 你的域名/admin 登录
  2. 在「产品中心 / 案例工程 / 新闻资讯 / 合作运营商」里增删改
  3. 前台刷新即可看到，不用重启服务
  4. 记得在「站点设置」里把公司名、电话、备案号改成真实信息
